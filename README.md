> > ### 中文
> > 在規劃旅遊或日常私房景點時市面上的地圖應用常充斥著業廣告、繁的選單，以及在「儲存地點與「規劃線」之間割裂的操作體驗。

> > > **「我希望能有一張乾淨、純粹屬於自己的地圖，可以自由建立彩色分類書籤；更重要的是，能透過最直覺的拖曳排序，自動把同一分類的地點依序連成一條動（1 ➔ 2 ➔ 3），讓行程規劃一眼看清、輕鬆順暢。」**

> > > 無需複雜的登入、沒有追蹤廣告不需依賴龐大的伺服器後端，打開瀏覽器就能直接規與出發。
